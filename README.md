# Веб зохиомжийн лабораторийн ажлууд

Энэ репо нь статик HTML, CSS, JavaScript сайтаар GitHub Pages ашиглан байршуулна.

- **Нийтэлсэн сайт:** https://siomai0-hi.github.io/
- **GitHub репо:** https://github.com/Siomai0-hi/Siomai0-hi.github.io

`main` салбарт өөрчлөлт оруулахад `.github/workflows/lab6-pages.yml` workflow сайтыг автоматаар байршуулна. Байршуулалтын явцыг репогийн **Actions** хэсгээс шалгана.

## Lab 7

Lab 7 нь Lab 6-ийн gallery-г харагдац өөрчлөхгүйгээр SCSS partial-ууд болгон зохион байгуулдаг. `npm install` дараа `npm run build` командаар `lab7/scss/main.scss`-ийг compressed `lab7/style.css` болгон compile хийнэ.
